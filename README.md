# Centre Lead Tracker Backend

## Project Overview

Centre Lead Tracker is a Lead Management System developed using Spring Boot. It helps coaching centres manage leads, owners, follow-ups and dashboard statistics.

## Tech Stack

- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- ModelMapper
- Lombok

## Features

- Dashboard API
- Centre Management
- Owner Management
- Lead Source Management
- Lead Status Management
- Lead Management
- Follow Up Management
- Pagination
- Soft Delete (Archive Lead)
- Global Exception Handling
- DTO Architecture
- Validation

## API Base URL

```
http://localhost:8080
```

## Run the Project

1. Clone the repository

```
git clone https://github.com/peeyushrasal16/CentreLead-Backend.git
```

2. Configure MySQL database in `application.properties`.

3. Run the application.
